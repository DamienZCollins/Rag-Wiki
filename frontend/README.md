# frontend

前端开发入口。

后端位于 `backend/`，前后端通过 HTTP 接口协作。阶段 8 的界面设计产出放在 `docs/前端设计/`，
按项目约定与 `backend/docs/` 一并不进入版本库，仅在本地保留：

```text
frontend/docs/前端设计/
├── 静态原型.html        客服对话页、Wiki 浏览页、评测报告页三合一
├── 静态原型预览.png      原型首屏预览
├── 设计系统.md          配色、字体、间距等设计令牌
├── 交互契约.md          路由、SSE 流式渲染、失败恢复约定
└── 审计记录.json        静态审计结果
```

原型不依赖后端，直接用浏览器打开即可，不需要启动服务，也不需要联网。
评测视图中的指标为原型示意数据，接入时需替换为真实评测结果。

任务拆分见 `../backend/docs/拆分任务/阶段8/任务拆分.md`。
