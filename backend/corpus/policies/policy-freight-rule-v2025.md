# 运费收取与承担规则

## 承担责任划分

| 场景 | 运费承担方 |
| --- | --- |
| 无理由退货 | 买家 |
| 质量问题退货 | 平台 |
| 发错货、少发漏发 | 平台 |
| 买家拒收（非质量问题） | 买家 |
| 超时未取件被退回 | 买家 |
| 送装过程损坏 | 平台 |

## 运费补贴上限

质量问题退货的退回运费按实际支付金额补贴，**单笔订单最高补贴 20 元**，超出部分由买家承担。

补贴在退货签收后 3 个工作日内退回原支付账户。

## 运费计算方式

- 计价重量：商品实际重量与体积重量取大者
- 续重单位：每 1kg 为一个续重单位，不足 1kg 按 1kg 计
- 偏远地区：新疆、西藏、内蒙古部分区域加收偏远附加费，附加费标准以承运商报价为准

## 包邮规则

单笔订单实付满 99 元包邮，生鲜类目满 129 元包邮。大件商品不参与包邮，运费在商品详情页单独列示。

优惠券、积分、红包抵扣后的实付金额作为包邮门槛的判定依据。

## 与其他权益的关系

- 运费险：见《运费险规则》
- 会员运费券：见《会员运费券规则》
- 大件商品退换运费：见《大件商品送装与退换》，不适用本节补贴上限

## 运费争议

买家对运费金额有异议的，可在订单完成前发起运费申诉，平台在 2 个工作日内复核。
