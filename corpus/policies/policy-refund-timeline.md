# 退款到账时效

## 退款触发时点

| 场景 | 触发时点 |
| --- | --- |
| 仅退款（未发货） | 审核通过后立即发起 |
| 退货退款 | 退货签收并验收通过后发起 |
| 拒收退回 | 商品退回仓库验收通过后发起 |
| 平台判责退款 | 判责结果生效后立即发起 |
| 物流丢件退款 | 承运商确认丢件后发起，见《物流轨迹异常处理》 |

## 到账时效

自退款发起起计算：

| 支付方式 | 到账时效 |
| --- | --- |
| 余额支付 | 实时到账 |
| 借记卡 | 1-3 个工作日 |
| 信用卡 | 3-7 个工作日 |
| 第三方支付 | 1-2 个工作日 |
| 分期付款 | 3-15 个工作日，需结清当期账单 |

到账时效由支付渠道决定，平台发起到渠道入账之间的时间不计入平台责任。

## 部分退款

订单使用优惠券、积分、红包的，按实付金额比例分摊退款，优惠部分不退回。

赠品随主商品退回的按主商品退款比例处理；赠品未退回的，按赠品标价从退款金额中扣减。

## 退款失败

退款因账户异常失败的，系统在 3 个工作日内重试；连续 3 次失败转人工处理并生成售后工单，流程见《工单流转与人工介入》。

## 退款进度查询

在「订单详情-退款进度」中查看当前节点。退款发起后超过约定时效未到账的，可发起催办。
