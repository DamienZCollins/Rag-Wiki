# 七天无理由退换货规则

## 适用范围

自签收次日起 7 个自然日内，商品未使用、不影响二次销售的，买家可申请无理由退货。

以下类目**不适用**无理由退货：

| 类目 | 说明 |
| --- | --- |
| 生鲜食品 | 仅受理质量问题，见《生鲜商品售后规则》 |
| 定制商品 | 按买家要求定制，无质量问题不退 |
| 贴身衣物 | 已拆封的不予退货 |
| 数字内容 | 已激活或已下载的不予退货 |
| 大件家具家电 | 走送装流程，见《大件商品送装与退换》 |

## 时效口径

- 起算点：以物流签收时间为准，签收当日不计入
- 截止点：第 7 个自然日 24:00 前提交申请
- 超时处理：超时申请系统自动驳回，买家可申请人工复核

## 商品状态要求

退回商品需同时满足：配件齐全、包装完整、无使用痕迹、赠品一并退回。

已激活的电子设备需先解除账号绑定，未解除的做拒收处理。

## 退货运费

无理由退货的退回运费由买家承担；质量问题退货的退回运费由平台承担，责任判定依据见《质量问题的判定与举证》。

买家自付的退货运费可用运费险或会员运费券抵扣，见《运费险规则》与《会员运费券规则》。

## 换货规则

同款同规格换货免收来回运费。换货商品需有库存，无库存的转为退货退款处理。

换货后不再重复享受 7 天无理由期限，新商品签收后重新起算。
